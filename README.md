# ระบบบริหารอพาร์ทเม้นท์ v2 — คู่มือติดตั้ง

ใช้ฟรีทั้งหมด หน้าเว็บอยู่บน **GitHub Pages** และข้อมูลเก็บใน **Google Sheet** ผ่าน Apps Script
(โครงสร้างเดียวกับระบบจองร้านตัดผม)

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `backend.js` | โค้ดหลังบ้าน **คัดลอกไปวางใน Apps Script** (และใช้เป็นโหมดทดลองด้วย) |
| `config.js` | ใส่ URL ของ Apps Script **แก้ไฟล์นี้ไฟล์เดียว** |
| `index.html` | หน้าแรก เลือกเข้าเป็นผู้เช่าหรือเจ้าของหอ |
| `admin.html` | ส่วนเจ้าของหอ (O1–O16) |
| `tenant.html` | ส่วนผู้เช่า (T1–T13) |
| `bill.html` | ใบแจ้งหนี้ / ใบเสร็จ สำหรับเปิดจากลิงก์และพิมพ์ |
| `app.css`, `common.js` | หน้าตาและฟังก์ชันกลาง (ไม่ต้องแก้) |
| `demo.js` | โหมดทดลอง (ถ้าใส่ URL แล้วไฟล์นี้จะไม่ถูกใช้) |

> ถ้ายังไม่ใส่ URL ใน `config.js` ระบบจะเปิดเป็น **โหมดทดลอง** อัตโนมัติ
> ข้อมูลตัวอย่างจะอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น

---

## 1. ตั้งหลังบ้าน (Google Sheet + Apps Script) · ~10 นาที

1. สร้าง **Google Sheet ใหม่** (ใช้ไฟล์ใหม่ ไม่ต้องใช้ไฟล์ของเวอร์ชันแรก)
2. เมนู **ส่วนขยาย → Apps Script** → ลบโค้ดเดิมใน `Code.gs` → วางเนื้อหาไฟล์ `backend.js` ทั้งหมด → กดบันทึก
3. ด้านบนเลือกฟังก์ชัน **`setup`** → กด **Run** → กดอนุญาตสิทธิ์
   (Advanced → Go to … (unsafe) → Allow) ระบบจะขอสิทธิ์ Sheet และ Drive (ใช้เก็บรูปสลิปและรูปแจ้งซ่อม)
4. **Deploy → New deployment** → ⚙️ เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

> ถ้าแก้ `backend.js` ภายหลัง ต้องกด **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** ทุกครั้ง (URL เดิมใช้ต่อได้)

## 2. ตั้งหน้าเว็บ (GitHub Pages) · ~5 นาที

1. สร้าง repository ใหม่ เช่น `apartment`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้
3. แก้ `config.js` ใส่ URL จากขั้นที่ 1.5:
   ```js
   const API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
   ```
4. Settings → Pages → Branch: `main` → Save
5. เปิด `https://sameephong.github.io/apartment/` → เลือก **เจ้าของหอ** → รหัสผ่านเริ่มต้น **1234**

## 3. ตั้งค่าครั้งแรก

0. หน้าแรกกด **✏️ ข้อมูลหอ** ใส่ชื่ออพาร์ทเม้นท์ ที่อยู่ เบอร์โทร (แสดงในแอปผู้เช่า บิล และใบเสร็จ)
1. เมนู เพิ่มเติม › ตั้งค่า ใส่ค่าน้ำ ค่าไฟ ค่าส่วนกลาง วันครบกำหนดชำระ เบอร์พร้อมเพย์ และข้อความบอกวิธีจ่ายเงินสด
2. **เปลี่ยนรหัสผ่าน** จาก 1234
3. **สร้างห้องทีละหลายห้อง** แล้วแก้ค่าเช่าห้องที่ราคาไม่เท่ากันในผังห้อง
4. เช็คอินผู้เช่าเดิมทีละห้อง: ใส่ชื่อ เบอร์ วันสัญญา **เลขมิเตอร์ปัจจุบัน**
   ถ้าเป็นผู้เช่าเดิมที่จ่ายมัดจำไปแล้ว ให้ **ปิด “ออกบิลแรกเข้าอยู่”**
5. ตั้ง **รหัสเข้าระบบผู้เช่า** (ตัวเลข 4–8 หลัก ตั้งเองหรือกดสุ่ม) แล้วกด **ส่งลิงก์ + รหัสให้ผู้เช่าทาง LINE**
   ดู/เปลี่ยนรหัสทุกห้องได้ที่ เพิ่มเติม › รหัสเข้าระบบผู้เช่า

## ใช้งานประจำเดือน

1. **สิ้นเดือน:** หน้าแรก → จดมิเตอร์ (แท็บน้ำ แล้วแท็บไฟ) กรอกแค่เลขครั้งนี้ ระบบบันทึกเองทุกครั้งที่พิมพ์
2. กด **ถัดไป: ออกบิล** → ตรวจยอดรวมและคำเตือน (เช่น ค่าไฟสูงผิดปกติ) → **ออกบิล**
3. ผู้เช่าเห็นบิลในแอปทันที จ่ายได้ 2 แบบ
   - **โอน:** ผู้เช่าแนบสลิป → หน้าแรกของเจ้าของหอขึ้น “อนุมัติสลิป” → กด **อนุมัติ** หรือ **ไม่อนุมัติ** (เลือกเหตุผล)
   - **เงินสด:** เจ้าของหอกด 💵 ที่บิล ใส่จำนวนเงินที่รับ ระบบคิดเงินทอนให้
4. อนุมัติหรือรับเงินแล้ว ระบบออก **ใบเสร็จพร้อมเลขที่** ให้ผู้เช่าในแอปอัตโนมัติ
5. **บิลพิเศษ** (ค่าซ่อม ค่าปรับ ฯลฯ): บิล/เงิน → + ออกบิล → ออกบิลรายห้อง
6. **ย้ายออก:** ผังห้อง → แตะห้อง → ย้ายออก → ใส่เลขมิเตอร์วันออกและค่าเสียหาย ระบบคำนวณเงินคืนมัดจำให้

## แจ้งเตือนเข้ากลุ่ม LINE (ไม่บังคับ)

ตั้งค่า → แจ้งเตือนเข้ากลุ่ม LINE → ใส่ Channel access token และ Group ID (วิธีหาเหมือนระบบจองร้านตัดผม) → กดทดสอบส่ง
- แจ้งทันทีเมื่อผู้เช่าส่งสลิปหรือแจ้งซ่อม
- ถ้าต้องการสรุปทุกเช้า 9 โมง: ใน Apps Script เลือกฟังก์ชัน `installDailyTrigger` → Run ครั้งเดียว

## หมายเหตุ

- ข้อมูลทั้งหมดอยู่ใน Google Sheet ของคุณ เปิดดูได้ แต่ **อย่าเปลี่ยนชื่อชีตหรือหัวคอลัมน์**
- รูปสลิปและรูปแจ้งซ่อมเก็บใน Google Drive โฟลเดอร์ “ไฟล์อพาร์ทเม้นท์ - ชื่อหอ”
- ระบบเตือนเมื่อมีคนส่งสลิปรูปเดิมซ้ำ แต่**ตรวจกับธนาคารไม่ได้** ควรเช็กยอดเข้าในแอปธนาคารก่อนอนุมัติ
- ใส่ PIN ผิด 5 ครั้ง ห้องนั้นจะถูกล็อก 15 นาที · ใส่รหัสเจ้าของหอผิด 10 ครั้ง ล็อก 15 นาที
- ยังไม่มี: อ่านเลขมิเตอร์จากรูปถ่าย, ส่ง LINE หาผู้เช่าทีละคนอัตโนมัติ (ตอนนี้กดส่งเองผ่านปุ่ม LINE)
